# Politica di sicurezza

## Segnalare una vulnerabilità

**Non aprire una issue pubblica.** Usa la funzione di GitHub *Report a vulnerability* nella scheda **Security** del repository (segnalazione privata), oppure scrivi a **`<!-- TODO: indirizzo email di sicurezza -->`**.

Indica, se possibile: descrizione, passi per riprodurla, impatto stimato, versione interessata.

Per vulnerabilità che riguardano **dati di minori** la priorità è massima.

## Cosa aspettarsi

- Conferma di ricezione entro 7 giorni.
- Una valutazione e un piano di correzione appena possibile.
- Riconoscimento pubblico del segnalante, se lo desidera, dopo la correzione.

Il progetto non ha ancora rilasci. Questa sezione verrà aggiornata al primo rilascio.
