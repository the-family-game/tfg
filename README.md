# TFG – The Family Game

Un gioco per famiglie, accessibile a tutte le età e sicuro per i minori.

> Stato: fase di impostazione. Nessuno stack tecnico è ancora stato scelto (vedi `docs/adr/`).

## Come lavoriamo

Il progetto segue lo **Spec-Driven Development (SDD)**: nessuna riga di codice senza una specifica approvata.
Le regole sono nella [constitution](docs/constitution.md).

| Cartella | Contenuto |
|---|---|
| `docs/constitution.md` | Principi e regole del progetto |
| `docs/specs/NNNN-nome/` | Specifica, piano e task di ogni funzionalità |
| `docs/adr/` | Architecture Decision Records (formato Nygard) |
| `docs/glossario.md` | Termini del dominio |
